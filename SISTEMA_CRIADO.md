## 🚀 **Como Executar:**

### 1. **Instalar dependências:**
```bash
npm run install-all
```

### 2. **Configurar banco de dados:**
- Instale PostgreSQL
- Crie database `erp_remotenyx`
- Configure `.env` no servidor

### 3. **Executar:**
```bash
npm run dev
```

### 4. **Acessar:**
- **Frontend**: http://localhost:3000
- **Backend**: http://localhost:5000
